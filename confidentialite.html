SafariDoku

Politique de confidentialité

Dernière mise à jour : 13 novembre 2026

SafariDoku est un jeu de logique pour iPhone. Pour toute question : contact@noham.eu.

En bref. Le jeu se joue sans créer de compte. Ta progression reste sur ton iPhone. Les publicités sont fournies par Google, qui reçoit pour cela quelques données techniques ; tu choisis si elles peuvent servir à personnaliser les annonces. Le parrainage enregistre un identifiant anonyme, sans nom ni adresse.

Ce qui reste sur ton appareil. Ta progression, tes étoiles, tes graines, tes animaux, ton pseudo et tes réglages sont enregistrés sur ton iPhone. Nous ne les recevons pas.

Publicité. Le jeu affiche des publicités fournies par Google AdMob. Pour les afficher, les mesurer et lutter contre la fraude, Google reçoit : l'identifiant publicitaire de l'appareil (seulement si tu l'as autorisé), une position approximative déduite de l'adresse IP, les publicités vues et les interactions avec elles, et des données techniques de diagnostic et de performance. Dans l'Espace économique européen, au Royaume-Uni et en Suisse, le jeu te demande ton accord au premier lancement ; iOS te demande ensuite si tu autorises le suivi. Tu peux changer d'avis à tout moment : dans le jeu, Réglages puis « Mes choix pour les pubs » ; sur l'iPhone, Réglages > Confidentialité et sécurité > Suivi. Si tu refuses, les publicités restent mais ne sont pas personnalisées. Pour savoir comment Google utilise ces données : https://policies.google.com/technologies/partner-sites

Parrainage. Si tu utilises le parrainage, le jeu enregistre dans iCloud (service CloudKit d'Apple) ton code de parrainage et un identifiant technique calculé à partir de ton compte iCloud, rendu illisible par hachage. Il sert à trois choses : retrouver ton code après une réinstallation, compter les amis qui l'ont utilisé, et empêcher qu'un même compte utilise plusieurs codes. Aucun nom, aucune adresse e-mail, aucun contact n'est enregistré. Ces données sont conservées tant que le parrainage existe ; écris-nous avec ton code pour les faire supprimer.

Game Center. Si tu es connecté à Game Center, tes scores (niveaux terminés, étoiles, meilleure série) sont envoyés à Apple pour les classements. Tu peux te déconnecter de Game Center dans les Réglages de l'iPhone.

Achats. Les achats intégrés sont traités par Apple. Nous ne recevons ni ton nom ni tes moyens de paiement.

Enfants. Le jeu s'adresse à tous les publics et n'est pas conçu spécialement pour les enfants. Nous ne collectons sciemment aucune donnée permettant d'identifier un enfant.

Tes droits. Tu peux demander l'accès aux données te concernant, leur rectification ou leur suppression en écrivant à l'adresse ci-dessus. Si tu résides dans l'Union européenne, tu peux aussi saisir l'autorité de protection des données de ton pays (en France, la CNIL).

Modifications. Cette page sera mise à jour si le jeu change. La date en haut de page indique la dernière version.
